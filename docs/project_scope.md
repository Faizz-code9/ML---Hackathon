\# PathSnap - Project Scope



\## Project Overview

PathSnap is a machine-learning-based map-matching project that aims to reconstruct realistic vehicle trajectories by aligning noisy GPS observations with a road network.



\## Problem Statement

GPS trajectories contain positional errors that may cause observations to be incorrectly associated with road segments. Selecting roads independently for each GPS point may also result in sequences that are inconsistent with the road network.



The project investigates machine-learning-based candidate road evaluation and sequence-based decoding to improve trajectory reconstruction.



\## Objectives

\- Explore GPS trajectory data and road-network structure.

\- Identify candidate road segments for GPS observations.

\- Extract relevant features for machine-learning models.

\- Compare multiple machine-learning approaches.

\- Investigate sequential decoding using HMM and Viterbi.

\- Evaluate predictions using suitable metrics.



\## Scope

The project focuses on software-based GPS map matching, trajectory analysis, machine-learning model comparison, and road-network consistency evaluation.



\## Expected Outcome

A pipeline capable of mapping GPS observations to plausible road segments and reconstructing a consistent trajectory.



\## Current Progress

Initial repository exploration and trajectory connectivity analysis have been performed. Further data analysis, model experimentation, evaluation, and pipeline development are ongoing.
